# AI LinkedIn Automation

An automated content system that researches AI topics, drafts educational LinkedIn posts, checks their quality, creates supporting visuals, and publishes approved content.

## Why it matters

The goal is not simply to post more. It is to help a professional build trust by consistently turning complex AI news into useful, understandable content.

## What it does

- Finds relevant AI and technology topics
- Extracts the important business and technical lessons
- Generates and reviews posts through multiple AI agents
- Creates matching images
- Schedules publishing and records performance

## Technology

Python, AI model APIs, LinkedIn automation, image generation, and GitHub Actions.

## Run

Install the dependencies, configure the required credentials as environment variables, and run:

```bash
pip install -r requirements.txt
python main.py
```

Review generated content before enabling automatic publishing.
